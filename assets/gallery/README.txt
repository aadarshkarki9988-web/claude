ROYAL INN — GALLERY FOLDER
==========================

Drop your gallery photos (and videos) into THIS folder and they appear on the
Gallery page automatically — no renaming, no code changes.

- Images: .jpg .jpeg .png .webp
- Videos: .mp4 .webm .mov
- Files show in name order (2 before 10), so prefix with numbers to control
  order, e.g. 01-terrace.jpg, 02-sekuwa.jpg, 03-bar.jpg ...
- Sub-folders are fine too — everything inside is included.
- This README is ignored.

After adding files, just refresh the Gallery page.
