ROYAL INN — MENU DISH PHOTOS
============================

Each dish on the Menu page has a small photo slot next to it. Generate an
appealing photo for a dish, save it here using EXACTLY the file name listed
below (all lowercase, .jpg), and it appears automatically — no code changes.

Until a file exists, a tasteful placeholder box shows in its place, so you
can add photos gradually.

TIPS
  - JPG, roughly square (e.g. 800x800 or 1000x1000). It's shown as a small
    rounded thumbnail, so keep the dish centred and filling the frame.
  - Bright, appetising, top-down or 45° food-photography style suits best.
  - Variants share one photo (e.g. all Chowmein use chowmein.jpg).
  - Want a photo for a specific variant instead? Tell me and I'll split it.
